# Performance

How oneyaml-csharp compares with the other .NET YAML libraries on speed and memory. Every task runs on the same inputs for every library, through the oneyaml benchmark kit, [oneyaml-kit](https://github.com/recursive-ai-oss/oneyaml-kit). The tables and charts below are generated from the kit's result file; none of the numbers is typed by hand.

The figures are measured, not bounds: they hold for the workloads, versions and host named in the method line of each block. A run that is marked as not publishable is a smoke result; it shows the layout and the rough picture, and it is not a claim.

What is compared:

- **Loading and writing**, typed and untyped, against YamlDotNet, SharpYaml and VYaml. oneyaml-csharp is measured on both its reflection path and its generated-metadata path.
- **Reading a document for editing**, and **editing** it, against the closest .NET equivalents, such as SharpYaml's syntax tree.
- **Applying a patch** against Yaml2JsonNode with JsonPatch.Net, the usual .NET route for a JSON Patch on YAML. That route converts to a JSON tree and does not keep the file's formatting, so the comparison is of the work, not of equal output.

Each generated table names the competitors of every task, and a cell without a number says why.

The kit's [benchmark notes](https://github.com/recursive-ai-oss/oneyaml-kit/blob/main/docs/benchmarks.md#tasks) define each task and how it is timed. The kit also decides when a difference in time or memory is too small to call a win or a loss; the [verdict rules](https://github.com/recursive-ai-oss/oneyaml-kit/blob/main/docs/benchmarks.md#verdicts) say where those bands lie and how a verdict is reached.

## Running the benchmarks yourself

The published numbers come from the kit, which runs every library on the same workloads. To measure a checkout of this repository there, set `KIT_ONEYAML_CSHARP_SRC` to it and follow the kit's [benchmark notes](https://github.com/recursive-ai-oss/oneyaml-kit/blob/main/docs/benchmarks.md).

This repository also has BenchmarkDotNet benchmarks in `bench/OneYaml.Benchmarks`, used while developing; their README says how to run them. Their results are not the published ones.
